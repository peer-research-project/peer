## Actionable findings

1. **P1: prose survives when all evidence claims are dropped.** `web/src/lib/papers/evidence.ts:325-353` clears proposal summary, novelty and findings summary only if the source corpus itself has zero entries. For an invented abstract containing an unrelated source sentence and a model report whose every quoted evidence is invented, `keepAll` drops every claim but leaves these narrative fields intact. `web/src/components/reader/report-sections.tsx:226-236` renders the proposal as fact. Require support for the prose or suppress it when its supporting claims do not survive; cover a nonempty corpus with zero supported evidence.
2. **P1/P2: source change is not verified against server reading.** `web/src/components/reader/use-reading.ts:152-170` caches the response under the current client source fingerprint, but `web/src/app/api/papers/[id]/reading/route.ts:115-125` independently fetches its own record and does not check that parameter. A stale/failed enrichment on the server can return and store a no-abstract reading under the enriched client key for a day, overriding the new client reading. Compare source identities before caching/display or otherwise reconcile; test divergent server and client records and a source change during an in-flight request.
3. **P1: legacy/inconsistent model-abstract content remains visible.** `web/src/lib/papers/reading.ts:1072-1073` changes the provenance sentence when the reading has no abstract, but the report sections still render cached report content (`report-sections.tsx:226-236`). Version bump prevents old v7 cache hits, but a v8 report and a later inconsistent reading can coexist, including through finding 2. Suppress or reverify report content against current evidence; test combined availability and rendered content.
4. **P2: regression tests removed rather than re-aimed.** c58c30e7 deletes three `uploadsReady` readiness predicate tests (`web/src/lib/papers/use-uploads-available.test.ts`), and removes the predicate while changing button visibility. Retain or replace equivalent behavioral coverage showing unknown/unavailable states prevent transfer, available permits it, while entry visibility is unconditional; include retry transitions. Static markup tests do not exercise clicks, drops, fetch failure or retry.
